# ADR: Four hubs as accepted SPOFs

**Status:** accepted (2026-08-29)

## Context

Replicas on `proxmox-applications-*`, `proxmox-observability-*`, and `rpi4` do
not absorb a failure of the shared edge, database, internal LB, or NAS.

## Decision

These four are accepted single points of failure:

1. `xcloud-postgres` — PostgreSQL, PgBouncer, Redis
2. `xcloud-caddy` — public HTTPS (and game UDP)
3. `proxmox-lb` — internal HTTP, S3/Loki/Mimir front door
4. `truenas-scale` — NFS file state and two of three Garage data dirs

## Consequences

Do not document the fleet as multi-region HA. Design around hub recovery
(runbooks, waitForHost, Attic on db-1) rather than pretending a replica saves
the hub.
